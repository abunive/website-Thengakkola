# KTU Activity Point Management System

## Overview

A web-based activity point management system developed to help students discover activities, manage events, and track activity-related information.

## Technologies Used

- React.js
- Firebase
- JavaScript
- HTML5
- CSS3

## Key Features

- Student activity and event management
- Event discovery
- Calendar-based activity management
- Student interest-based information
- Notifications
- Activity reporting

## My Contribution

This project was developed as a team mini project. I contributed as a team member to the development and documentation of the application.

## Project Type

Academic Mini Project

## Purpose

The system aims to make activity management more organized and accessible for students by providing a centralized web-based platform.
